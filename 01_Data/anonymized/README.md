# 익명화 데이터

원본 결제 로그에서 결제자를 식별할 수 있는 두 컬럼만 가명 처리한 데이터입니다.

| 컬럼 | 처리 |
|---|---|
| 카드번호 | 같은 값은 같은 가명으로 치환 (C0001, C0002 ...) |
| 승인번호 | 같은 값은 같은 번호로 치환 (10000001부터 순번) |

- 같은 값끼리 같은 가명을 쓰므로 영수증 묶음, 방문 횟수 같은 집계는 원본과 동일하게 나옵니다.
- 나머지 컬럼(영업일자, 승인시간, 메뉴명, 가격 등)은 원본 그대로입니다.
- `icecream.csv`는 원본 결제 로그와 같은 구조(헤더 2행)라서 노트북이 읽는 `../01_Data/raw/` 폴더에 복사하면 그대로 실행됩니다.
- `expanded_icecream.csv`는 판매수량만큼 행을 복제한 파생 파일입니다 (초기 버전 노트북용).
- 나머지 파일(메뉴 목록, 가격 인상표, 요일/시간대/월별/메뉴별 집계)은 개인정보가 없어 원본 그대로입니다.
